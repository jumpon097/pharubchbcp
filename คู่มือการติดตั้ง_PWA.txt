คู่มือการนำระบบ BCP ขึ้น GitHub Pages (PWA)
========================================================================

ไฟล์ในโฟลเดอร์นี้ถูกตั้งค่าให้รองรับการทำ PWA (Offline App) เรียบร้อยแล้ว
คุณจะได้แอปที่มีข้อมูลยาและรูปภาพพร้อมใช้งานทั้งหมด

📂 วิธีอัปโหลดขึ้น GitHub:
------------------------------------------------------------------------
1. สร้าง Repository ใหม่ใน GitHub (ตั้งชื่อเช่น bcp-pharmacy)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, sw.js, manifest.json, icon-*.png) ขึ้นไป
3. ไปที่แท็บ Settings > Pages เลือกกิ่ง (Branch) เป็น main หรือ master แล้วกด Save
4. รอสักครู่ GitHub จะสร้างลิงก์ให้ เช่น https://[ชื่อคุณ].github.io/bcp-pharmacy/

👨‍⚕️ วิธีให้พยาบาล/ห้องยา ติดตั้งระบบ (ทำครั้งเดียวตอนมีอินเทอร์เน็ต):
------------------------------------------------------------------------
1. เข้าไปที่ลิงก์ GitHub Pages ของคุณด้วย Google Chrome หรือ Edge
2. ที่แถบ URL ด้านบนขวา จะมีปุ่มหน้าจอคอมพิวเตอร์ หรือกดจุด 3 จุด แล้วเลือก "Install App (ติดตั้งแอป)"
3. ระบบ BCP จะกลายเป็นแอปพลิเคชันอยู่บนหน้า Desktop ทันที!
4. เมื่อเกิดเหตุฉุกเฉิน (ไม่มีเน็ต) สามารถดับเบิ้ลคลิกแอปนี้จากหน้าจอ แล้วใช้งานได้ 100%
