ระบบนี้ฝังฐานข้อมูล 016 update และ List 2 ไว้ภายใน index.html แล้ว

การทำงาน:
1. เปิดระบบครั้งแรก ใช้ฐานข้อมูลที่ฝังใน HTML ทันที ไม่ต้องมีไฟล์ Excel อยู่ข้างนอก
2. เมื่อต้องการอัปเดต ไปที่ ตั้งค่าระบบ > ฐานข้อมูลแพ้ยาและการจับคู่ยา
3. เลือกอัปเดตเฉพาะ 016 update, เฉพาะ List 2 หรือทั้งสองไฟล์ก็ได้
4. ระบบเก็บไฟล์เวอร์ชันใหม่ใน IndexedDB ของเครื่องนั้น และใช้ต่อเนื่องแม้ปิดโปรแกรม
5. ปุ่ม “กลับไปใช้ฐานข้อมูลที่ฝังใน HTML” จะลบเวอร์ชันที่อัปเดตในเครื่องและคืนค่าเดิม

หมายเหตุ: การอัปเดตมีผลเฉพาะเครื่อง/โปรไฟล์เบราว์เซอร์ที่อัปโหลดไฟล์ หากต้องการให้ฐานข้อมูลใหม่เป็นค่าเริ่มต้นของทุกเครื่อง ต้องสร้าง index.html เวอร์ชันใหม่ที่ฝังไฟล์ชุดล่าสุด
