=============================

- คอลัมน์ B: ชื่อผู้ป่วย -> ล้างข้อมูลอัตโนมัติ
- คอลัมน์ L: Diagnosis ผู้ป่วยนอก -> ล้างข้อมูลอัตโนมัติ

- data/qr16015-allergy150666.xlsx ชุดนี้ถูกล้าง B/L แล้ว
